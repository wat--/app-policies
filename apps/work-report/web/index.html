作業実績 Web 版

パソコンから報告書と請求書を PDF に

iPhone・iPad アプリ「作業実績」で Google スプレッドシートと連携している記録を読み込み、アプリと同じ体裁の作業実績報告書と請求書の PDF を出力します。記録の修正もできます。

  • アプリで連携しているのと同じ Google アカウントでログインしてください。
  • このページが読み書きするのは、アプリ「作業実績」が作成したスプレッドシートだけです。Google ドライブのほかのファイルにはアクセスしません。
  • 記録はこのページを置いているサーバーには送られません。ブラウザと Google の間で直接やり取りします。
  • 請求書は、アプリの「設定」→「請求書」をオンにしていると出力できます。
