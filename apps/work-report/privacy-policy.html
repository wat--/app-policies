プライバシーポリシー

最終更新日: 2026年11月26日

本プライバシーポリシーは、iPhone・iPad 用アプリ「作業実績」と、パソコンのブラウザで使う「作業実績 Web 版」（以下あわせて「本アプリ」）における情報の取り扱いについて説明します。

1. 本アプリが扱う情報

情報保存場所送信先
作業の記録（日付、業務開始・終了の時刻、休憩時間、実施概要）端末内Google 連携を使う場合のみ、利用者自身の Google ドライブ（下記 2.）
報告書の設定（タイトル、プロジェクト名、会社名・氏名、注意書き）端末内同上
請求書の内容（請求先、名前、住所、電話番号、単価、振込先の口座、備考）端末内同上
取り込みに使う Excel ファイル保存しません（読み取った記録だけを端末内に保存）なし
Google 連携のためのログイン情報（アクセス用のトークン）端末内（キーチェーン）。Web 版はブラウザのタブを閉じるまでの一時的な保存のみGoogle のみ
広告配信に関する情報広告事業者（Google）あり（下記 3.）

本アプリに独自のアカウント登録はなく、開発者のサーバーは存在しません。作業の記録や請求書の内容を開発者が受け取ることは一切ありません。これらが広告事業者に送られることもありません。

作成した報告書・請求書の PDF は、利用者が共有の操作をしたときに、利用者が選んだ宛先（メール、ファイルなど）へ渡されます。

2. Google スプレッドシートとの連携について

Google 連携は任意の機能です。連携しなくても、記録と PDF の出力は利用できます。

  • 連携すると、利用者自身の Google ドライブにスプレッドシート（「作業実績報告書」と、請求書を使う場合は「請求書」）を作成し、上記の記録・設定・請求書の内容を保存して、アプリとの間で同期します。
  • 本アプリが Google に求める権限は「このアプリで作成したファイルの参照・編集・作成・削除」だけです。利用者の Google ドライブにあるほかのファイル、メール、連絡先などにはアクセスしません。
  • 通信は利用者の端末と Google の間で直接行われ、開発者のサーバーを経由しません。開発者は、利用者の Google アカウントの情報やスプレッドシートの内容を取得・保存しません。
  • Google から受け取った情報は、アプリの画面に表示し、スプレッドシートと同期するためにのみ使用します。広告の配信や第三者への提供には使用しません。

本アプリによる、Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に準拠します。

連携をやめるには、アプリの「設定」で「連携をやめる」を選びます。Google アカウントの「サードパーティ製のアプリとサービス」から、本アプリのアクセス権を削除することもできます。連携をやめても、作成済みのスプレッドシートは利用者の Google ドライブに残ります。不要な場合は Google ドライブで削除してください。

Web 版について

Web 版は、上記の Google 連携を使って、利用者自身のスプレッドシートを読み、PDF の作成と記録の修正を行います。処理は利用者のブラウザの中で行われ、記録や作成した PDF が、このページを置いているサーバーや開発者に送られることはありません。Web 版は記録をブラウザに保存せず、開くたびにスプレッドシートから読み込みます。

Web 版のページには、楽天アフィリエイトのウィジェット広告を表示しています。表示される商品は自動的に選択され、Cookie を用いてリンクのクリックや購入が計測されます。記録や請求書の内容が広告事業者に送られることはありません。詳細は 楽天アフィリエイトをご確認ください。

3. 広告について

iPhone・iPad 用アプリは、Google AdMob を使用して画面の上部にバナー広告を表示しています。AdMob は広告配信のために、デバイス情報、IP アドレス、広告の表示・操作に関する情報、診断情報などを収集する場合があります。本アプリは位置情報の利用許可を求めず、AdMob による位置情報の収集も無効にしています。また、トラッキング許可（App Tracking Transparency）を求めないため、広告識別子（IDFA）を用いたトラッキングは行いません。

詳細は Google のプライバシーポリシーをご確認ください：
https://policies.google.com/privacy

本アプリは解析ツールを使用していません。

4. データの削除

端末内の記録・設定・請求書の内容は、本アプリを削除すると消去されます。Google ドライブに作成したスプレッドシートは利用者のものであり、Google ドライブでいつでも削除できます。

5. 本ポリシーの変更

本ポリシーは必要に応じて改定することがあります。重要な変更がある場合は、本ページで告知します。
