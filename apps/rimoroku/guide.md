# リモ録 使い方・接続ガイド

## 1. 準備するもの

- Android TV / Google TV 搭載のソニー製テレビ BRAVIA（開発時の確認機種: KJ-49X8000H）
- 録画機能を使う場合は、テレビに接続した録画用 USB ハードディスク
- iPhone とテレビが同じ Wi‑Fi（自宅の LAN）に接続されていること

## 2. テレビ側の設定

1. テレビのリモコンの「ホーム」ボタンを押し、「設定」→「ネットワークとインターネット」→「リモート起動」（機種により「リモートスタート」「ネットワークからの起動」）をオンにします。オフだとテレビが待機中に反応せず、予約や電源オンができません。
2. テレビの IP アドレスを確認します。「ホーム」→「設定」→「ネットワークとインターネット」→「ネットワークの状態」に表示されます（例: 192.168.1.201）。
3. IP アドレスは固定しなくても構いません。アプリは同じネットワークのテレビを自動で探し、アドレスが変わっていれば切り替えます。固定したい場合は、ルーターの DHCP 予約のほか、テレビ側でも設定できます: 「ホーム」→「設定」→「ネットワークとインターネット」→ 接続中のネットワーク →「IP 設定」を「静的」にして、現在のアドレスをそのまま入力します。

## 3. アプリとテレビの接続（初回のみ）

1. アプリを開き、左上の歯車から「設定」を開きます。
2. 「同じネットワークのテレビを探す」を押し、見つかったテレビを選びます。見つからない場合は「テレビの IP アドレス」に手順 2 で確認したアドレスを入力します。
3. 「テレビに PIN を表示して接続」を押します。テレビの画面に 4 桁の PIN が表示されます。
4. 表示された PIN をアプリに入力し、「PIN で接続」を押します。
5. 初回は iOS から「ローカルネットワーク上のデバイスの検索と接続」の許可を求められます。「許可」を選んでください。

接続後の認証情報は iPhone 内に保存され、次回からはアプリを開くだけで接続します。IP アドレスを変えるときや別のテレビにつなぐときは、設定の「接続をクリア」で削除してからやり直してください。

## 4. 基本の使い方

- **番組表**: 右上の番組表アイコンから開きます。地上・BS・CS を切り替え、日付を選び、番組をタップして「この番組を録画予約」。繰り返し（毎日・毎週・月〜金など）も選べます。
- **録画予約一覧**: テレビに登録されている予約を確認・削除します。
- **録画済み番組一覧**: 録画済みの番組を新しい順に表示します。左スワイプで削除、右スワイプで削除保護の切り替えができます。削除は取り消せません。
- **リモコン**: トップ画面の下にあります。動画アプリのボタンは「すべてのアプリ・ボタンの編集」で入れ替え、ブロックの並びは「ボタン配置の編集」で変更できます。

## 5. 外出先から使う（VPN）

このアプリはテレビと直接通信するため、そのままでは自宅の Wi‑Fi の中でしか使えません。外出先から使うには、VPN で自宅のネットワークに接続します。おすすめは Tailscale です（無料プランで十分です）。

### 5-1. Tailscale を使う場合

必要なもの: 自宅で常時動いている Mac または Windows PC（スリープしない設定にしておく）、Tailscale のアカウント。

1. 自宅の PC に Tailscale をインストールしてログインします（https://tailscale.com/）。
2. その PC を「サブネットルーター」にします。自宅の LAN のアドレス範囲（例: 192.168.1.0/24）を広告する設定です。
   - Mac: ターミナルで `tailscale up --advertise-routes=192.168.1.0/24` を実行（Tailscale アプリの設定からも可能）。
   - Windows: 管理者権限のコマンドプロンプトで同じコマンドを実行します。
3. Tailscale の管理画面（https://login.tailscale.com/admin/machines）で、その PC の「Subnet routes」を承認（Approve）します。
4. iPhone に Tailscale アプリを入れ、同じアカウントでログインして接続をオンにします。
5. これで外出先でも、アプリの IP アドレス設定はそのまま（例: 192.168.1.201）で使えます。

ポイント:
- 自宅の PC の電源が切れていたりスリープしていると使えません。
- iPhone 側は Tailscale をオンにしている間だけ自宅の LAN に届きます。自宅の Wi‑Fi にいるときはオフでも構いません。
- ルーター自体が Tailscale や WireGuard に対応していれば、PC の代わりにルーターを使えます。

### 5-2. ほかの VPN を使う場合

WireGuard や OpenVPN、ルーター付属の VPN 機能でも同じことができます。条件は「iPhone から自宅 LAN のアドレス（192.168.x.x）に直接届くこと」です。接続後、アプリの設定はそのままで使えます。

### 5-3. やってはいけないこと

ルーターのポート転送でテレビをインターネットに直接公開するのは避けてください。テレビとの通信は暗号化されておらず、認証情報が第三者に読み取られるおそれがあります。

## 6. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| PIN が表示されない | IP アドレスが正しいか、テレビの電源が入っているか、同じ Wi‑Fi につながっているか |
| 「認証が必要です」と出る | 設定の「接続をクリア」→ PIN 登録をやり直す |
| 待機中のテレビに反応しない | テレビの「リモート起動」をオンにする |
| 予約時に「対応するチャンネルが見つかりません」 | 設定の地域が合っているか。テレビでそのチャンネルが受信設定されているか |
| 外出先で使えない | VPN が接続中か。自宅の PC（サブネットルーター）が動いているか |
| 番組表が読み込めない | インターネット接続を確認する。番組表サイト側の変更の場合はアプリの更新をお待ちください |

## 7. 注意事項

- 本アプリはソニー株式会社とは関係のない個人開発アプリです。BRAVIA はソニーグループ株式会社の商標です。
- 番組表の情報は外部の番組表サービスから取得しています。放送内容は予告なく変更される場合があります。
- 録画・予約の可否や動作はテレビの仕様に従います。すべての機種での動作を保証するものではありません。
