# リモ録 使い方・接続ガイド

## 1. 準備するもの

- Android TV / Google TV 搭載のソニー製テレビ BRAVIA（開発時の確認機種: KJ-49X8000H）
- 録画機能を使う場合は、テレビに接続した録画用 USB ハードディスク
- iPhone とテレビが同じ Wi‑Fi（自宅の LAN）に接続されていること
- nasne（任意）: 同じネットワークに接続されていること

## 2. テレビ側の設定

### 2.1 リモート起動をオンにする

テレビのリモコンの「ホーム」ボタンを押し、「設定」→「ネットワークとインターネット」→「リモート起動」（機種により「リモートスタート」「ネットワークからの起動」）をオンにします。オフだとテレビが待機中に反応せず、予約や電源オンができません。

### 2.2 IP アドレスの確認と固定（必要な場合のみ）

通常は不要です。アプリが同じネットワークのテレビを自動で探します。自動で見つからないときや、外出先（5. を参照）で使う予定があるときだけ設定してください。

- IP アドレスの確認: 「ホーム」→「設定」→「ネットワークとインターネット」→「ネットワークの状態」（例: 192.168.1.201）。
- IP アドレスの固定: ルーターの DHCP 予約のほか、テレビ側でも設定できます。「ホーム」→「設定」→「ネットワークとインターネット」→ 接続中のネットワーク →「IP 設定」を「静的」にして、現在のアドレスをそのまま入力します。

## 3. アプリとテレビの接続（初回のみ）

### 3.1 接続の手順

① iPhone をテレビと同じ Wi‑Fi につなぎ、アプリを開きます。初回は iOS から「ローカルネットワーク上のデバイスの検索と接続」の許可を求められるので「許可」を選んでください。

② アプリが同じネットワークのテレビを自動で探し、「BRAVIA-4K-…」のような名前で表示します。IP アドレスの確認や入力は不要です。

③ テレビ名の横の「接続する」を押します。テレビの画面に 4 桁の PIN が表示されます。

④ 表示された PIN をアプリに入力し、「PIN で接続」を押します。

### 3.2 テレビが見つからないとき

「もう一度探す」を押してください。それでも見つからない場合は、6. の「テレビが見つからない」を確認するか、「IP アドレスを直接入力する（設定）」から 2.2 の方法で調べた IP アドレスを入力し、「テレビに PIN を表示して接続」を押してください。

### 3.3 接続情報の保存

接続後の認証情報は iPhone 内に保存され、次回からはアプリを開くだけで接続します。自宅のネットワークにいる間は、テレビの IP アドレスが変わっても自動で探し直すので、再登録は不要です。別のテレビにつなぎ直すときは、設定の「接続をクリア」で削除してからやり直してください。

## 4. 基本の使い方

### 4.1 番組表から予約する

トップ画面の「番組表から録画予約する」ボタンで開きます。地上・BS・CS を切り替え、日付を選び、番組をタップして「この番組を録画予約」を押します。繰り返し（毎日・毎週・月〜金など）も選べます。地上波の地域は設定の「地上波の地域」で選びます（初期値: 東京）。

### 4.2 録画予約一覧

予約を日時の近い順に確認・削除します。nasne を登録している場合は、上のタブで「すべて（テレビと nasne をまとめて表示）」「テレビ」「nasne」を切り替えます。最初は「すべて」です。

### 4.3 録画済み番組一覧

録画済みの番組を新しい順に表示します。左スワイプで削除、右スワイプで削除保護の切り替えができます。削除は取り消せません。nasne を登録している場合は、4.2 と同じタブで切り替えます。

### 4.4 リモコン

トップ画面の下にあります。動画アプリのボタンは「すべてのアプリ・ボタンの編集」で入れ替え、ブロックの並びは「ボタン配置の編集」で変更できます。

### 4.5 nasne を使う（任意）

nasne（ソニー製）が同じネットワークにあれば、アプリの起動時に自動で見つけて登録します。IP アドレスや暗証番号の入力は不要です。登録内容は次回以降も保持されます。見つからないときは、設定の「nasne」→「同じネットワークの nasne を探す」を押すか、IP アドレスを直接入力してください。

登録後は、次のことができます。

- 番組表の予約シートで「録画先」をテレビと nasne から選ぶ。どちらを最初に選んでおくかは、設定の「番組表からの既定の録画先」で決められます。
- 予約一覧・録画済み一覧で、テレビと nasne をまとめて、または別々に確認・削除する。

ご注意:

- nasne の地上波は、nasne を設置したときの地域のチャンネルで録画されます。地上波を nasne に予約するときは、設定の「地上波の地域」を nasne と同じ地域にしてください。違うと「チャンネルが見つかりません」と表示されます。BS・CS は地域に関係なく使えます。
- nasne の録画を iPhone で再生する機能はありません（著作権保護方式のため）。

## 5. 外出先から使う（VPN）

### 5.1 仕組みと準備

このアプリはテレビや nasne と直接通信するため、そのままでは自宅の Wi‑Fi の中でしか使えません。外出先から使うには、VPN で iPhone から自宅のネットワークに接続します。

**先に自宅で一度接続しておいてください。** テレビや nasne を自動で探す機能は、同じ Wi‑Fi の中でしか働きません。外出先では、自宅で見つけて保存したアドレスをそのまま使います。そのため、外出先で使う予定があるなら、テレビと nasne の IP アドレスを固定しておくと確実です（2.2 を参照）。

VPN の条件は「iPhone から自宅 LAN のアドレス（192.168.x.x）に直接届くこと」です。WireGuard、OpenVPN、ルーター付属の VPN 機能など、この条件を満たすものであれば何でも使えます。接続後、アプリの設定はそのままで使えます。

### 5.2 設定例: Tailscale の場合

ここでは例として Tailscale（無料プランあり）で設定する手順を示します。

必要なもの: 自宅で常時動いている Mac または Windows PC（スリープしない設定にしておく）、Tailscale のアカウント。

① 自宅の PC に Tailscale をインストールしてログインします（https://tailscale.com/）。

② その PC を「サブネットルーター」にします。Tailscale につないだ iPhone から、その PC を経由して自宅の LAN（例: 192.168.1.0/24 の範囲の機器）に届くようにする設定です。

- Mac: ターミナルで `tailscale up --advertise-routes=192.168.1.0/24` を実行します（Tailscale アプリの設定からも可能）。
- Windows: 管理者権限のコマンドプロンプトで同じコマンドを実行します。

③ 管理画面で、自宅の LAN への経路を許可します。Tailscale では ② の設定をしただけでは使えず、管理画面で許可して初めて有効になります（知らないうちに経路が開かないための仕組みです）。

- パソコンか iPhone のブラウザで https://login.tailscale.com/admin/machines を開き、① と同じアカウントでログインします。
- 「Machines」の一覧で、② の PC の名前を押します。
- 開いたページの下部にある「Subnets」の欄で、「192.168.1.0/24」を許可します（編集ボタンからチェックを入れて保存します）。
- 「Subnets」の欄で「192.168.1.0/24」が許可済みになっていれば完了です。

画面の表記は Tailscale 側の変更で変わることがあります。

④ iPhone に Tailscale アプリを入れ、同じアカウントでログインして接続をオンにします。

⑤ これで外出先でも、自宅で保存したアドレス（例: 192.168.1.201）のままテレビと nasne に届きます。アプリ側の設定変更は不要です。

ポイント:

- 自宅の PC の電源が切れていたりスリープしていると使えません。
- iPhone 側は Tailscale をオンにしている間だけ自宅の LAN に届きます。自宅の Wi‑Fi にいるときはオフでも構いません。
- ルーター自体が Tailscale や WireGuard に対応していれば、PC の代わりにルーターを使えます。

### 5.3 やってはいけないこと

ルーターのポート転送でテレビや nasne をインターネットに直接公開するのは避けてください。通信は暗号化されておらず、認証情報が第三者に読み取られるおそれがあります。

## 6. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| テレビが見つからない | テレビの電源が入っているか。iPhone がテレビと同じ Wi‑Fi につながっているか（モバイル通信や別の Wi‑Fi では見つかりません）。iPhone の「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で「リモ録」がオンか |
| nasne が見つからない | nasne の電源と LAN 接続。iPhone が同じ Wi‑Fi につながっているか。見つからない場合は設定の「nasne の IP アドレス」に直接入力もできます |
| PIN が表示されない | テレビの電源が入っているか。選んだテレビ（または入力した IP アドレス）が正しいか |
| 「認証が必要です」と出る | 設定の「接続をクリア」→ PIN 登録をやり直す |
| 待機中のテレビに反応しない | テレビの「リモート起動」をオンにする（2.1） |
| 予約時に「対応するチャンネルが見つかりません」 | 設定の「地上波の地域」がテレビ（nasne に予約するときは nasne）の地域と合っているか。そのチャンネルが受信設定されているか |
| 外出先で使えない | VPN が接続中か。自宅の PC（サブネットルーター）が動いているか。自宅で一度接続したか。テレビや nasne の IP アドレスが自宅にいたときから変わっていないか |
| 番組表が読み込めない | インターネット接続を確認する。番組表サイト側の変更の場合はアプリの更新をお待ちください |

## 7. 注意事項

- 本アプリはソニー株式会社とは関係のない個人開発アプリです。BRAVIA、nasne はソニーグループ株式会社の商標です。
- 番組表の情報は外部の番組表サービスから取得しています。放送内容は予告なく変更される場合があります。
- 録画・予約の可否や動作はテレビ・nasne の仕様に従います。すべての機種での動作を保証するものではありません。
