このサイト（tail-studio.com）は、公開している iOS アプリのプライバシーポリシーやサポート窓口を置くために運用しています。「さくらインターネットとお名前.com にお金を払っている。自前サーバーは攻撃が怖いし、もっと安くならないか」と思い立って、契約内容を棚卸ししました。

結論から言うと、Web 本体はすでに GitHub Pages で無料でした。お金がかかっているのはメールボックスとドメイン更新の 2 つだけで、どちらも Cloudflare に寄せれば年額をおよそ半分にできます。自前サーバーは最初から不要でした。この記事は、その調査結果と移行計画の記録です。移行が終わったら結果を追記します。

## まず契約を棚卸しした

契約の全体像は、過去のメールと DNS を見れば分かります。やったことは次の 3 つです。

1. 受信メールを「さくらインターネット」「お名前.com」の送信元で検索して、申込完了・請求・更新通知を読む
2. `dig` でドメインの A / CNAME / MX / TXT / NS レコードを引いて、何がどこを向いているか確認する
3. サイトの HTTP ヘッダーを見て、実際にどこから配信されているか確認する

```bash
dig +short tail-studio.com A
dig +short tail-studio.com MX
dig +short tail-studio.com NS
dig +short tail-studio.com TXT
curl -sI https://tail-studio.com/ | grep -i server
```

結果はこうでした。

| 項目 | 向き先 | 意味 |
|---|---|---|
| A レコード | 185.199.108〜111.153 | GitHub Pages の IP。Web は GitHub が配信している |
| HTTP の server ヘッダー | GitHub.com | 同上 |
| NS レコード | ns1/ns2.dns.ne.jp | DNS はさくらのネームサーバー |
| MX レコード | *.sakura.ne.jp | メールはさくらのメールボックスで受けている |
| TXT レコード | SPF（さくらの IP）、Google サイト確認、DMARC | メール送信元認証と Search Console 用 |

つまり「さくらのレンタルサーバー」を契約しているつもりでしたが、実態は **さくらのメールボックス**（メール専用の最小プラン）で、同時に DNS もさくらに置いている状態でした。Web サーバーは借りていません。

## 何にいくら払っていたか

| 契約 | 用途 | 年額（税込） |
|---|---|---|
| さくらのメールボックス | 問い合わせ用アドレスの送受信、DNS ホスティング | 1,320 円 |
| お名前.com の .com 更新 | ドメイン本体 | 約 1,700〜2,000 円 + サービス維持調整費 25.5%（2026 年 10 月時点） |
| 合計 | | 約 3,500〜4,000 円 |

月に 300 円程度なので、もともと高くはありません。ただ、お名前.com の「サービス維持調整費」は 2026 年に入ってから 25% 前後で毎月のように料率が変わっていて、更新のたびに請求額が読みにくいのが気になっていました。

また、さくらインターネットは 2026 年 8 月に販売管理システムへの不正アクセスを公表しています。私の契約も対象で、9 月にさくら側からサーバーパスワードの強制変更とメールパスワードの変更推奨の連絡が来ました。二次被害は確認されていないとのことですが、メールだけのために置いているサービスで管理対象が増えるのは避けたい、というのも見直しの動機になりました。

## 自前サーバーを立てない理由

「安くするなら自宅サーバーや格安 VPS に Web とメールを載せる」という発想になりがちですが、今回は最初から選択肢に入れませんでした。

- **Web は静的サイトで足りる**。プライバシーポリシーとブログだけなら、GitHub Pages や Cloudflare Pages のような静的ホスティングで無料、しかも CDN が前段にいるので DDoS や脆弱性スキャンを自分で受け止める必要がありません。
- **メールサーバーの自前運用は割に合わない**。受信はスパム攻撃の的になり、送信は Gmail や iCloud に届かせるための SPF / DKIM / DMARC と IP レピュテーション管理が延々と必要です。問い合わせ窓口 1 つのために背負うものではありません。
- **攻撃されて困るのは Web より「ドメインとメールの乗っ取り」**。守るべきは登録事業者（レジストラ）のアカウントと、連絡先メールの到達先です。ここは二段階認証と移管ロックで守るのが本筋で、サーバーを持つかどうかとは別の話です。

## 移行先の選び方

### ドメイン：Cloudflare Registrar

Cloudflare Registrar は、レジストリの卸値と ICANN 手数料だけで販売していて上乗せがありません。.com は年 10.46 ドル、2026 年 11 月 1 日のレジストリ値上げ後でも 11 ドル台の見込みです。日本円で 1,800 円前後になります（為替で上下します）。調整費のような変動分はありません。Whois 情報の非公開化と移管ロックは無料で最初から有効です。DNS ホスティングも無料で付くので、さくらの DNS 依存を同時に外せます。

お名前.com から出るときの条件も確認しました。登録から 60 日以内は他社移管ができませんが、このドメインは 2026 年 1 月登録なので問題ありません。移管すると有効期限が 1 年延びるため、お名前.com 側の自動更新が走る前（期限の 1 か月以上前）に済ませると二重払いを避けられます。

### メール：Cloudflare Email Routing（転送）

候補は 3 つありました。

| 方式 | 年額 | 特徴 |
|---|---|---|
| さくらのメールボックスを継続 | 1,320 円 | 今のまま。安いが管理対象が 1 社増える |
| iCloud+ のカスタムメールドメイン | iCloud+ 契約内なら 0 円 | 本物のメールボックス。DKIM も Apple 側で付く。iCloud メールの主アドレスが必要 |
| Cloudflare Email Routing | 0 円 | 独自ドメイン宛を Gmail 等に転送。返信は Gmail の「他のアドレスから送信」で行う |

問い合わせアドレスに実際に届いているものを見返すと、ASO 業者の営業メールと海外からのスパムが大半で、ユーザーからの問い合わせは年に数通です。本格的なメールボックスは要らないと判断して、Email Routing の転送方式にしました。iCloud メールを主アドレスとして使っていないので、iCloud+ 方式は今回は見送りです。

返信側は、Gmail の「他のメールアドレスからメールを送信」に独自ドメインのアドレスを登録します。SMTP サーバーには、2026 年 6 月から使えるようになった Cloudflare 自身の SMTP 送信（smtp.mx.cloudflare.net、ベータ）か、従来どおり smtp.gmail.com とアプリパスワードを使います。前者なら「〜経由で送信」という表示が付かず、SPF も Cloudflare 側の include 1 行で済みます。

## 移行手順と順番の注意

一番大事なのは **順番** です。DNS をさくらに置いたままさくらを解約すると、Web もメールも一度に止まります。先に DNS を移し、次にメール、最後にドメイン移管と解約です。

1. **Cloudflare にゾーンを追加する**。無料プランでよく、今の DNS レコード（GitHub Pages 用の A 4 本と www の CNAME、Google サイト確認の TXT、SPF、DMARC）をそのまま登録します。GitHub Pages 向けのレコードは最初は「DNS only」（プロキシなし）にしておくと、GitHub 側の HTTPS 証明書がそのまま使えます。
2. **お名前.com のネームサーバーを Cloudflare に変更する**。ここでさくらの DNS 依存が切れます。反映まで数時間見ておきます。
3. **Email Routing を有効にする**。宛先の Gmail を確認し、独自ドメインのアドレスから Gmail への転送ルールを作ります。MX と SPF は Cloudflare が自動で書き換えます。テストメールを送って転送を確認したら、Gmail に送信用アドレスを登録して返信もテストします。
4. **ドメインを Cloudflare Registrar へ移管する**。お名前.com で移管ロックを解除して AuthCode を取得し、Cloudflare 側で移管を申請します。お名前.com からの承認メールに応答すれば数日で完了します。Whois 公開代行を一時的に外す必要が出ることがあります。
5. **さくらのメールボックスを解約する**。Web とメールが Cloudflare 経由で動いていることを数日確認してからにします。必要なら、解約前にメールソフトから既存メールを書き出しておきます。
6. **お名前.com の自動更新を止めて退会する**。移管完了後、二重請求がないことを確認します。

移行後の年額は 1,800 円前後、現状のおよそ半分になる見込みです。

## App Store 側への影響

App Store Connect に登録しているサポート用メールアドレス、サポート URL、プライバシーポリシー URL は独自ドメインのものなので、**どれも変更不要**です。変わるのは「そのアドレス宛のメールをどこで受けるか」と「DNS をどこで管理するか」だけで、ユーザーから見えるものは何も変わりません。

個人開発でアプリを出すとき、連絡先に個人のメールアドレスを晒したくなくて独自ドメインを取った、という人は多いと思います。その目的のためなら、月額のメールボックスを借りなくても、ドメイン代だけで転送方式が成り立ちます。

## 現在地

2026 年 10 月 31 日のうちに、移行を終えました。計画どおりに進んだ部分と、つまずいた部分を記録します。

### 結果

| 項目 | 移行前 | 移行後 |
|---|---|---|
| ドメイン | お名前.com | Cloudflare Registrar（期限 2028 年 1 月 1 日） |
| DNS | さくら | Cloudflare |
| メール受信 | さくらのメールボックス | Cloudflare Email Routing で Gmail に転送 |
| メール送信 | さくらの SMTP | Gmail の「別のアドレスから送信」 |
| 年額 | 約 3,500〜4,000 円 | 約 1,800 円（為替で変動） |

移管料は 10.46 ドルでした。.com のレジストリ値上げは 11 月 1 日で、前日に済ませたので 0.71 ドル安くなりました。さくらのメールボックスは、払い済みの 2027 年 1 月 15 日で終了します。

### つまずいた点

- **WHOIS 公開代行を外さないと移管できない**。お名前.com は、公開代行が有効なままの .com を他社へ移管できません。解除すると、移管が終わるまで登録者情報が公開される可能性があります。そのため、Cloudflare のカード登録と入力を済ませ、決済の直前に解除し、すぐ決済しました。移管後は Cloudflare が登録者情報を自動で伏せます。実際に WHOIS を確認すると、氏名、住所、郵便番号は非公開で、都道府県と国だけが見えます。
- **承認しないと 96 時間で拒否される**。移管を申請すると、お名前.com から「トランスファー申請に関する確認」のメールが届きます。放置しても自動承認されません。メール内のリンクで承認すると、レジストリ上の移管が数時間で終わりました。
- **Cloudflare の送信機能は有料**。Email Sending は Workers Paid プランが必要でした。無料で送信元を独自ドメインにするには、Gmail の「他のメールアドレスを追加」で smtp.gmail.com を使います。2 段階認証をオンにしてアプリパスワードを作り、SPF に Google の include を足します。
- **切り替え直後も旧サーバーに届く**。MX を切り替えた直後に、旧サーバーへまだ 1 通届いた例がありました。さくらを即解約せず、数時間から 1 日は様子を見るのが安全です。
- **登録者メールの認証が必要**。移管後、Cloudflare から登録者メールの認証依頼が届きます。ICANN の規則で、期限内に認証しないとドメインが停止されることがあります。

### 手順を整えて分かったこと

DNS を先に移し、メールを移し、最後にドメインを移す順番にしたので、サイトとメールは一度も止まりませんでした。さくらを先に解約していたら、DNS ごと消えるところでした。
